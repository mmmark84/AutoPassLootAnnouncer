Announces group loot drops the moment they drop, and rolls need, greed or pass for you.

Built for raids where everyone is asked to pass on loot. Blizzard's Pass on Loot option is server side: with it on, the server never sends you the roll, so you never find out what dropped until people start looting. This addon replaces that option with automated passing you can actually see.

Features

  • Announces on the roll, not on the corpse, so you see drops even when someone else loots the body
  • Roll actions per quality and per kind — need, greed, pass, or leave the window up, set separately for BoP, BoE and stackable BoE drops, so the epic gems pass themselves while a BoE pattern off the same boss stops and waits for you
  • A loot window that says what dropped as it drops, totals the night per person, and can hold each roll a few seconds so you get one click to take any of it back
  • Sessions — split the log per boss or per pull the way a damage meter splits segments, with the last ten kept to switch back to
  • Presets for whole sets of settings, so the night's raid rules and the way you loot a five-man are two clicks apart, with a one-line code to share either
  • Single announcer election — when several people in the group run the addon, they agree on one announcer so the drop is posted once, with nothing to configure
  • Never armed between sessions — automated rolling starts each login off, on, or behind a prompt, whichever you pick
  • A drop popup that appears when something drops, says what it was and goes again — the pack's haul read in the quiet after the pull, never on screen during one
  • Say it with a prefix of your own, a random cheerful pepe, or a random silly line off a list of fifty

Roll actions

Pick a quality with the tabs, then set what happens to each kind of drop at that quality. Quality on its own is a poor guide to whether a drop is worth stopping for — at epic, all three kinds want different answers:

DropKindTypical setting
Tier token, boss gearBoPPass
Pattern, BoE weaponBoEWindow — somebody has been waiting for it
Epic gem, nether vortexBoE stackPass — it is a commodity

The four actions are Window (nothing happens, the roll window stays up for you), Pass, Greed (auto-confirms the bind prompt) and Need. Uncommon, rare, epic and legendary each get their own three rows. Poor and common are left alone entirely — no auto-roll, the window stays up exactly as it would without the addon running.

Bind type comes from the roll itself, so it is the server's answer for that exact roll. Stackability is the item's maximum stack size, so a single epic gem still reads as stackable. If something has not resolved in time, the roll is left alone rather than guessed at.

The loot window

Off by default. The Loot window button at the bottom of the options panel cycles through it, because the two things people asked for are points on one line, from "tell me nothing" through "tell me" to "tell me and wait for me".

Loot windowWhat happens
OffNo window. Rolls are answered the moment they drop and Blizzard's roll windows are left alone
Drops onlyA window lists what dropped and who took it, as it happens. Rolls are still answered straight away
3s / 5s / 8s / 12sAlso holds each roll the addon is going to answer for that long, counting down, so you can take one back

Above the line are pending rolls. The countdown is the row itself: a band the full width of it, draining away leftwards behind the item name, so how long is left reads from the corner of your eye without the number being read. It warms from green through amber to red as it goes. Click a pending row and the auto-roll is dropped and Blizzard's own window opens for that item with the full remaining roll timer on it. Nothing here shortens a roll, and doing nothing still rolls for you — that is what keeps this from being Blizzard's roll window with a shorter timer.

Below the line, what already happened, totalled per person and grouped by what it is: epics first, then rares, then uncommons, and within each quality the ones that stack ahead of the ones that do not, each group under its own caption. A trash farm is settled up by its stackable epics and rares — the gems, the hearts, the marks — so those sit at the top rather than wherever the last green pushed them. Three Hearts of Darkness that all went the same way read as one row with an x3 beside the name, because what this window is being asked is who ended up with what.

All of it, not the last thirty rows. The list is the whole session above the quality threshold, however long it ran, and the rows scroll. This is where a night of farming is added up, and a total that quietly stopped counting would be a wrong total. Your share of the coin sits in the header beside it.

Once it is on it stays on screen, because a window that comes and goes is one you cannot find, aim at or resize. Drag it by the header or the body, size it from the corner grip, hover a row for the tooltip and shift-click one to link it in chat. Position and size are both remembered per account. Right-click anywhere on it — header, body or a row — for a short menu:

MenuEffect
ShowThe quality threshold, offered as the qualities themselves — Uncommon and better up to Legendary only, each in its own colour with a tick on the one in force
ShowingWhich session the list is reading: current, or one of the filed ones
Start a new sessionFiles what is on screen and starts counting from empty
Clear the drop logEmpties every session. Asks first, unless there is nothing to lose
Close this windowSame as the X in the header

The threshold is one setting shared by this window and the popup, and it starts at uncommon: nothing below that is ever logged, because the server only rolls for items at the group's loot threshold and up.

Sessions

Start a new session files what the window is showing and starts counting from empty — the same move a damage meter makes when it splits a fight off into its own segment. The last ten are kept, and Showing switches between them and the current one, each row saying when it ran and how many drops are in it.

That exists because what did that boss drop and what has tonight dropped are different questions, and the only way to ask the first one used to be to clear the log — which lost the answer to the second. Clearing is now only for when you want the lot gone.

While a filed session is on show the header says which, where the right-click hint usually sits, because a window quietly showing last pull's drops during this one is the only thing sessions could get wrong. Rolls pending above the list are always the live ones whichever session is being read, and new drops always go into the current session — looking back never stops anything being recorded.

What counts as a drop

Only what the group was actually offered: an item the server rolled for — the window you would have answered without this addon — and, under master loot, one a loot addon announced. Nothing else.

That rule matters, because "receives loot" cannot tell a drop from anything else that arrives through the loot system:

Reads as lootIs it a drop?
Soul Dust, Lesser Astral EssenceNo — someone disenchanted the green they just won
Tainted Core, Vashj's Vial RemnantNo — fight mechanics that happen to be items
Greys and commons in a groupNo — handed out round-robin, no roll, no window
Quest pickups, herbs, anything you loot soloNo
The green the party rolled onYes
A stack of Nether Vortex someone wonYes
A tier token the master looter handed outYes, if Gargul or LootReserve announced it

A drop gets its row the moment it is put up, with no name beside it, and gains the winner's when somebody loots the corpse — so an epic stack is on screen as it drops rather than minutes later. Show filters what you are looking at, not what gets kept: everything that qualifies goes in, and widening the threshold brings it all back. The log is kept between logins, shared across your characters, and is a record of what the group was offered rather than of what you picked up.

The drop popup

Off by default, and deliberately not the loot window in another guise. The loot window is a fixture: you turn it on, it stays where you put it, and it is where a roll counts down and where you click to take one back. A window you may have to answer is a window that has to stay.

This is the opposite. It appears when something drops, says what it was, and goes — the thing you glance at in the quiet after a pull, while the healer drinks and somebody is looting. Each drop puts the clock back to the full time, so a pack arrives as one window rather than as five, and it is emptied on the way out so the next pull opens clean.

It is never on screen in a fight. What drops while you are fighting is held back and shown the moment you are not. That is the point of it rather than a limitation: the window is for the recovery period, not for the pull.

Squashed to one row it grows and shrinks with the pack; pulled down past one row it is that height every time and the rest scrolls on the mouse wheel, newest at the top. It has no header — a window this brief cannot spare the room — so it is dragged by its body and by its rows. Test beside the button fakes a pull's worth of drops so you can see it appear, fill up and go, and drag it somewhere while it is there. Nothing about a test is real: nothing announced, nothing rolled for, nothing logged.

Arming

Left-click the minimap button to arm or disarm automated rolling. Right-click opens the options, middle-click turns the loot window on and off.

Armed is never carried between sessions. The At login button decides what happens next time: Off stays disarmed until you arm it yourself, On arms straight away on the preset you were last using, and Ask puts a prompt in front of it so it is never armed without you saying so. The prompt carries a preset dropdown, so it is also where you pick the night's role.

Presets

A preset is the whole roll table plus everything about announcing and both windows, under a name. The raid's "pass on everything" rules and the way you loot a five-man are two clicks apart, and the login prompt on Ask is where you pick which one the night runs on.

Share codes put a preset on one line of text. /apla preset code opens a box to copy yours out of or paste somebody else's into, so a raid leader can hand the night's rules to twenty-four people in one message and they arrive as a new preset rather than overwriting anything.

Say it with

What goes in front of the item link is one setting with three choices, cycled by the button under the prefix box. One or the other, never two at once: only one thing can lead a line.

  • Prefix — Drop: [Cursed Vision of Sargeras]
  • Pepe — PepePogO [Cursed Vision of Sargeras]
  • Random — Ooh, a piece of candy! [Cursed Vision of Sargeras]

Pepe picks from 22 of the cheerful ones in Twitch Emotes 2.0. What goes out on the wire is the emote's name, so it becomes a picture only for readers who run Twitch Emotes themselves — everyone else sees the word. That addon is not a dependency and nothing breaks without it.

Random picks a line from a list of fifty — Another one., Ooh, shiny!, Mine! Mine! Mine!, The boss dropped its wallet: and so on. Plain text, so unlike a pepe it reads the same for everyone whatever they have installed, and a different one each drop. Both random modes re-roll once when the pick repeats the last one, so the same line rarely lands twice in a row.

Before it can do anything

For the addon to see rolls at all, Blizzard's own Pass on Loot option must be off (Interface → Combat). That option suppresses the roll server side and no addon can work around it.

Group loot rolls only happen in a group, on Group Loot or Need Before Greed. Solo, nothing is ever rolled for — so nothing is announced, rolled or logged when you are out on your own.
