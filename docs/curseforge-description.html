Announces group loot drops the moment they drop, and rolls need, greed or pass for you.

Built for raids where everyone is asked to pass on loot. Blizzard's Pass on Loot option is server side: with it on, the server never sends you the roll, so you never find out what dropped until people start looting. This addon replaces that option with automated passing you can actually see.

Features

  • Announces on the roll, not on the corpse, so you see drops even when someone else loots the body
  • Roll actions per quality and per kind — need, greed, pass, or leave the window up, set separately for BoP, BoE and stackable BoE drops, so the epic gems pass themselves while a BoE pattern off the same boss stops and waits for you
  • An optional loot window that says what dropped as it drops — movable, resizable, scrollable — and can hold each roll a few seconds so you get one click to take any of it back
  • Presets for whole sets of settings, so the night's raid rules and the way you loot a five-man are two clicks apart, with a one-line code to share either
  • Single announcer election — when several people in the group run the addon, they agree on one announcer so the drop is posted once, with nothing to configure
  • Never armed between sessions — automated rolling starts each login off, on, or behind a prompt, whichever you pick
  • Drop tracker — an optional log of everything that dropped this session and who won it, kept across logouts until you clear it
  • Say it with a prefix of your own, a random cheerful pepe, or a random silly line off a list of fifty

Roll actions

Pick a quality with the tabs, then set what happens to each kind of drop at that quality. Quality on its own is a poor guide to whether a drop is worth stopping for — at epic, all three kinds want different answers:

DropKindTypical setting
Tier token, boss gearBoPPass
Pattern, BoE weaponBoEWindow — somebody has been waiting for it
Epic gem, nether vortexBoE stackPass — it is a commodity

The four actions are Window (nothing happens, the roll window stays up for you), Pass, Greed (auto-confirms the bind prompt) and Need. Uncommon, rare, epic and legendary each get their own three rows. Poor and common are left alone entirely — no auto-roll, the window stays up exactly as it would without the addon running.

Bind type comes from the roll itself, so it is the server's answer for that exact roll. Stackability is the item's maximum stack size, so a single epic gem still reads as stackable. If something has not resolved in time, the roll is left alone rather than guessed at.

The loot window

Off by default. The Popup button at the bottom of the options panel cycles through it, because the two things people asked for are points on one line, from "tell me nothing" through "tell me" to "tell me and wait for me".

PopupWhat happens
OffNo window. Rolls are answered the moment they drop and Blizzard's roll windows are left alone
Drops onlyA window lists what dropped and who took it, as it happens. Rolls are still answered straight away
3s / 5s / 8s / 12sAlso holds each roll the addon is going to answer for that long, counting down, so you can take one back

Above the line are pending rolls. The countdown is the row itself: a band the full width of it, draining away leftwards behind the item name, so how long is left reads from the corner of your eye without the number being read. It warms from green through amber to red as it goes. Below the line, what already happened.

Once it is on it stays on screen, because a window that comes and goes is one you cannot find, aim at or resize. Drag it by the header or the body, resize it from the corner, and right-click anywhere on it for the quality threshold, Track drops and Clear the drop log. Position and size are both remembered.

Arming

Left-click the minimap button to arm or disarm automated rolling. Right-click opens the options, middle-click opens the drop log.

Armed is never carried between sessions. The At login button decides what happens next time: Off stays disarmed until you arm it yourself, On arms straight away on the preset you were last using, and Ask puts a prompt in front of it so it is never armed without you saying so. The prompt carries a preset dropdown, so it is also where you pick the night's role.

Drop tracker

Off by default. Turn on Track drops, then middle-click the minimap button for the log. A session lasts as long as you leave it: the log survives logouts and is emptied only when you say so, so a night of trash runs with a logout in the middle is still one list.

Two tabs, Everything and Mine. Non-stackables get a row each with the winner's name; stackables collapse to one row with a running total and sort to the top. Hovering a row shows the item tooltip, shift-clicking links it into whatever you are typing, and the header carries the session start and a running coin total.

The slider filters what you are looking at, not what gets kept. Everything that drops goes in, greys and quest items included, and the slider decides how far down the list you want to see. Drag it up to pull the night's epics out of a wall of vendor trash, drag it back down and they are all still there.

Say it with

What goes in front of the item link is one setting with three choices, cycled by the button under the prefix box. One or the other, never two at once: only one thing can lead a line.

  • Prefix — Drop: [Cursed Vision of Sargeras]
  • Pepe — PepePogO [Cursed Vision of Sargeras]
  • Random — Ooh, a piece of candy! [Cursed Vision of Sargeras]

Pepe picks from 22 of the cheerful ones in Twitch Emotes 2.0. What goes out on the wire is the emote's name, so it becomes a picture only for readers who run Twitch Emotes themselves — everyone else sees the word. That addon is not a dependency and nothing breaks without it.

Random picks a line from a list of fifty — Another one., Ooh, shiny!, Mine! Mine! Mine!, The boss dropped its wallet: and so on. Plain text, so unlike a pepe it reads the same for everyone whatever they have installed, and a different one each drop.

Before it can do anything

For the addon to see rolls at all, Blizzard's own Pass on Loot option must be off (Interface → Combat). That option suppresses the roll server side and no addon can work around it.

Group loot rolls only happen in a group, on Group Loot or Need Before Greed. Solo, nothing is ever rolled for — but Drops only works alone, which is the half that answers "show me what I looted".
